## Problem
Using Java, OOP, and LinkedList create a music playlist manager with an interactive terminal, that can be do the following:
  1. Sort by the song title or artist
  2. Show the original playlist
  3. Play the queue of songs
  4. Show the current song playing and the upcoming next song
  5. Terminal that asks what action the user would like to take
  6. The terminal should have a play (song player) and a queue representation with clean a design.
  7. Shuffle the playback queue randomly.
